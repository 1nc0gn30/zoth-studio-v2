## 5. AGY Perspective

**Feedback.** Auditing `azoth-local-agent` (`#018`) surfaced the highest-severity live security posture found so far in the whiteboard series:
1. **A live unauthenticated RCE surface on both localhost and Tailscale.** Because `tailscale serve` forwards `https://zothos.tailb0828c.ts.net:8136` to `127.0.0.1:8136`, and `web_ui.py` combines `allow_origins=["*"]` + `allow_credentials=True` + zero `Host` allowlist + zero auth/CSRF + unauthenticated `/api/vm/exec`, `/api/vm/install`, `/api/python/run`, and `/ws/terminal`, **any device on the tailnet or any malicious webpage opened in a local browser can execute arbitrary commands on the host**.
2. **Real functional regressions hidden under passing tests.** Despite `94 passed` in `pytest`, two single-key typos (`fallback.get("output")` vs `"reply"` in `web_ui.py:3705,3819` and `data.success` vs `data.ok` in `web_ui.py:2195`) silently broke offline Archon chat replies and browser cookie exports, while `tools/workspace.py:42` `startswith()` failed a live sibling-directory traversal probe and `mcp_server.py:84` crashed (`rc=1`) on a JSON array.
3. **Dual-theme inversion on both surfaces.** Visually inspecting all 14 screenshots revealed the cockpit ignores Dark Mode completely (blasting a white iframe inside Studio Dark Mode), while Studio's `AzothArchonGodModeTool.jsx` forces a dark slab with low-contrast dark label ink inside Editorial Ivory Light Mode.

**Enhancements for `v2`.**
- Turn `azoth-local-agent` into a genuinely hardened sovereign Archon daemon: strict loopback CORS/Host allowlists, token-gated privileged routes, `is_relative_to()` path containment everywhere, SSRF-guarded browser/fetch engines, sanitized Markdown/DOM rendering, and a clean light/dark cockpit that inherits `?theme=` seamlessly inside Zoth Studio.
- Upgrade `AzothArchonGodModeTool.jsx` and `public/index.html` into real offline-capable Archon workbenches (live `:8136` bridge when reachable + deterministic client-side DuckyScript linter, tool-schema inspector, and ReAct planner when offline) with zero `setTimeout` stubs.

**Appreciation.** The underlying engine breadth in `azoth-local-agent` is substantial — 35 real agent tool definitions, multi-engine CLI discovery (`engines/manager.py`), Playwright stealth browser lifecycle recovery, parameterized `.ducky` presets, stateful Python REPL worker sessions, and 94 already-passing pytest checks (with clean `RUN_LIVE_*` E2E gating and zero horizontal overflow or console errors across all 12 triple-viewport captures). Closing the security boundary, fixing the fallback key bugs, and aligning theme/docs/chroot parity will make `#018` a flagship hardened Archon runtime.
