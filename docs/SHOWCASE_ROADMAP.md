## What a Zoth Pill is

A Zoth Pill is one tool, 75 seconds, no slides. The format is fixed so the series stays recognisable and every episode is reusable as a live stream, a clip, a thread and a doc embed.

| Time | Beat | Rule |
|------|------|------|
| 0:00–0:08 | **Hook** | Name the tool and the one problem it kills. Say it out loud on camera. |
| 0:08–0:45 | **Proof** | Run it for real: real input, real output, real numbers. No mockups, no slides. |
| 0:45–1:05 | **So what** | Why it matters to a specific audience. One sentence, not a feature list. |
| 1:05–1:15 | **CTA** | Studio URL, the fact it is local and free, then the next pill. |

Three rules that make or break a pill:

1. **Show the output, not the UI.** Nobody subscribes for a dashboard tour — they subscribe for the artifact, the number, or the block.
2. **Never fake a control.** Every click drives real state; a pill that fakes a button gets caught in the replies.
3. **One pill, one idea.** If the tool needs two ideas, it is two pills.

## Series shape

- **83 pills**, 5 per week → **17 weeks** (2 slack slots left for retakes).
- **Four seasons**, grouped by category so each season inherits one audience instead of resetting it every week.
- **Cadence:** Mon–Fri, same posting time. Front-load the highest-signal pills (security, revenue) early in each week — editorial judgement on our side, not a measured engagement claim.

## Two routes to X

X live video is created in **Media Studio** (RTMP ingest); the X API v2 does not expose a broadcast-create endpoint (as of writing), so nothing can start a live stream programmatically. That splits the pipeline in two:

**Route A — live (the studio stream).** OBS → RTMP to the X ingest URL → live on X. Best for the launch of a season: stream the long-form session, then cut the pills out of the VOD. Use it weekly, not daily.

**Route B — pills as posted clips (the daily engine).** Record the pill with the repo's headless capture harness, encode, then post the clip + thread with `xurl` or the **Zoth X Connector** (`:8152`, systemd timer scheduler, multi-account). This is the workhorse route — it is schedulable, repeatable and needs nobody awake.

### Route B in practice

```bash
# 1. Start the studio locally
npm run dev            # studio on http://127.0.0.1:3000

# 2. Record one pill. scripts/capture_pill.mjs is the single new utility this
#    roadmap needs: scripts/capture_livestream_showcase.mjs generalised to take a
#    tool slug + output dir (that script hardcodes six routes and its own outDir).
node scripts/capture_pill.mjs --tool zoth-bolt --out dist/pills/

# 3. Post the clip + the pre-written copy from the plan
python3 -c "import json;p=[x for x in json.load(open('public/api/showcase.json'))['plan'] if x['id']=='zoth-bolt'][0];print(p['x_copy'])"
xurl media upload dist/pills/zoth-bolt.mp4     # -> MEDIA_ID
xurl media status --wait MEDIA_ID              # video is processed server-side
xurl post "$(cat dist/pills/zoth-bolt.txt)" --media-id MEDIA_ID
```

`xurl` is the X developer-platform CLI and needs a one-time OAuth that the account owner runs themselves (secrets never touch this session); confirm it with `xurl auth status`. The **Zoth X Connector** does its own OAuth through the Zoth Vault instead, so a fully scheduled pipeline needs no interactive auth at all.

Pills already exist as per-tool intro captures: 94 files (47 mp4, 46 webp, 1 webm) across 17 tools, named `<slug>-desktop.webp` / `<slug>-mobile.webp` and `<slug>-intro-desktop.mp4` / `<slug>-intro-mobile.mp4`. The site serves them from `public/studio-captures/` via `src/data/galleryManifest.js`; `dist/studio-captures/` holds the built copy. The roadmap reuses that naming so historical captures stay addressable instead of being recaptured.

## Per-pill production checklist

- [ ] Tool is running and the demo input is staged **before** recording
- [ ] Hook line written down (it is in the plan below) and said in one take
- [ ] Real output visible on screen within the first 15 seconds
- [ ] One number or artifact named explicitly (cost, margin, ports, bytes)
- [ ] No terminal `history`, no mounted tokens, no client names on screen
- [ ] `x_copy` posted with the clip, thread reply carrying the repo link
- [ ] Pill added to the season playlist and the studio tool page
